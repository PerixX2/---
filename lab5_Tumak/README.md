# Лабораторна робота №5 (Варіант 19)
**Тема:** Маятник під дією періодичної сили.

## Опис проєкту
Інтерактивна фізична симуляція математичного маятника з в'язким тертям під дією зовнішньої гармонічної сили. Чисельне інтегрування диференціального рівняння руху реалізовано методом Рунге–Кутти 4-го порядку (RK4) з візуалізацією через Windows API (GDI).

## Компіляція та запуск
Проєкт не потребує жодних зовнішніх бібліотек або `.dll`.
Для збірки за допомогою MinGW (`g++`):
```bash
g++ main.cpp -lgdi32 -luser32 -mwindows -static -o Pendulum_Lab5.exe
```

## Керування
- **Стрілки Вгору / Вниз** — зміна амплітуди зовнішньої сили
- **Стрілки Вліво / Вправо** — зміна частоти зовнішньої сили
- **P** — пауза / продовження симуляції
- **R** — скидання у початковий стан
